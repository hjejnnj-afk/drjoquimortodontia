# Landing Page Dr. Joaquim - Com Transições Entre Slides ✅

## 🎯 NOVO: Casos com múltiplos slides (ANTES → DEPOIS)

### Como funciona agora:

**CASO 01** (exemplo implementado):
- **Slide 1:** ANTES (rosto + dentes da criança)
- **Slide 2:** DEPOIS (resultado final adulto)
- **Indicação:** "Parte 1 de 2" e "Parte 2 de 2"
- **Texto:** Deixa claro que é o mesmo paciente

---

## 📐 FORMATO DAS IMAGENS:

### **Dimensão obrigatória:** 1080 × 1350 pixels (4:5 - vertical)

---

## 📁 ESTRUTURA:

```
assets/cases/
├── caso-01-parte1.jpg ✅ (ANTES)
├── caso-01-parte2.jpg ✅ (DEPOIS)
├── caso-02.jpg ⏳ (Você escolhe: 1 ou 2 slides)
└── ...
```

---

## 🚀 COMO ADICIONAR CASO COM 2 SLIDES:

1. Crie 2 imagens (1080×1350px cada)
2. Nomeie: caso-X-parte1.jpg e caso-X-parte2.jpg
3. Edite o HTML seguindo o exemplo do Caso 01
4. Use indicadores "Parte 1 de 2" nos textos
